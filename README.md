# Email-Application-java-Mini-Project

Small Java mini-project demonstrating a simple email-account system:
- user email generation
- temporary password generation
- mailbox capacity handling
- basic account operations

## Quick start (build & run)

This project uses Maven.

```bash
# build
mvn clean package

# run (example)
java -cp target/Email-Application-java-Mini-Project-1.0-SNAPSHOT.jar com.yourpackage.Main
